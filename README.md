# ☕ Coffee Cart App (POS & KDS)

An all-in-one, cross-platform tablet application designed for coffee cart operations. Built with **Kotlin Multiplatform (KMP)** and **Compose Multiplatform**, targeting Android, iOS, and Web.

## 🚀 Key Features
* **Kitchen Display System (KDS):** Real-time order queue management for baristas.
* **Point of Sale (POS):** Fast counter order entry.
* **Thermal Printing Support (Modular):** Abstracted `PrinterService` designed for seamless integration with thermal receipt printers (Epson ePOS / ESC/POS).
* **Cross-Platform:** Single codebase running natively across platforms.

## 🛠️ Tech Stack
* **Language:** Kotlin
* **UI Framework:** Compose Multiplatform
* **Architecture:** KMP Shared Logic + Clean Architecture (Repository Pattern)
